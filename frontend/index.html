About CyberVision AI

Comprehensive design, architecture, working methodology, and project documentation.

Project Specification

Project Name

CyberVision AI

Project Title

Cybersecurity Data Analysis and Visualization

Project Goal

To help users explore cybersecurity datasets, visualize security events, understand data quality, and identify patterns that may warrant further investigation.

Problem Statement

Modern cybersecurity telemetry generates vast amounts of connection logs, firewall records, and threat labels. Security teams and student researchers often lack lightweight, intuitive tools to quickly ingest heterogeneous CSV datasets, automatically normalize unpredictable column headers, detect suspicious multi-port scanning or brute-force patterns, and inspect data hygiene without heavy external cloud dependencies or complex enterprise SIEM setups.

Proposed Solution

CyberVision AI provides a clean, single-page, local-first analytics dashboard built with FastAPI, Pandas, and Chart.js. It dynamically adapts to available column attributes (IPs, protocols, ports, timestamps, attack categories, severities), calculates statistical and threat summaries, visualizes trends through 8 interactive charts, and exports structured reports in JSON and CSV formats—all running entirely locally without paid third-party APIs.

System Architecture

End-to-End Pipeline: From Raw CSV Ingestion to Interactive Visualization & Report Generation

Data Ingestion

Drag-and-drop CSV validation, encoding detection, size limits

FastAPI Backend

REST API endpoints, error handling, session state management

Pandas Engine

Header alias matching, severity normalization, anomaly heuristics

Chart.js Visuals

8 interactive charts, live filtering, responsive canvas

Export Engine

Downloadable CSV summaries and structured JSON reports

Working Methodology (7-Step Workflow)

01

Ingestion & Upload

User drops a CSV file. The backend verifies file extension, size limit (50MB), and attempts multi-encoding resolution (UTF-8, Latin-1, CP1252).

02

Validation & Cleaning

Pandas checks for empty rows and calculates missing value frequencies and duplicate entries to establish a data hygiene baseline.

03

Column Detection

Dynamic alias matching recognizes IPs, ports, protocols, attack labels, severities, and timestamps regardless of naming discrepancies.

04

Statistical Summaries

Computes mean, median, standard deviation, and range across numeric features (bytes, packets, durations) and categorical frequencies.

05

Chart Generation

Chart.js renders 8 distinct visualizations for protocol share, attack distribution, temporal timelines, and missing attributes.

06

Anomaly Heuristics

Rule-based detection flags high-severity events, multiple failed authentication attempts, port scan probes, and volumetric spikes.

07

Report Export

Generates downloadable, timestamped CSV summaries and structured JSON audit payloads with methodological boundaries.

Project Limitations

  • Performs offline, batch analysis on uploaded CSV files; does not function as a live packet sniffer or inline firewall.
  • Anomaly detection is based on rule heuristics and statistical thresholds, not certified real-world intrusion classification.
  • In-memory session state is browser-local and resets upon server restart to ensure data privacy.

Future Enhancements

  • Integration with live PCAP packet file ingestion via Scapy.
  • Evaluated machine-learning classifiers (Random Forest / XGBoost) trained on open benchmarks (e.g., CIC-IDS).
  • Direct SIEM webhook integrations (Syslog, Elasticsearch, Splunk).
  • Automated PDF security report compilation.
