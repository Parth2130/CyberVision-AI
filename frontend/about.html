About CyberVision AI

A specialized analytics and intelligence platform designed to decode complex network telemetry, surface security anomalies, and transform raw security logs into actionable visual insights.

Problem Statement

Modern enterprise environments generate millions of network telemetry records daily. Analyzing raw packet captures, firewall events, and intrusion logs manually is virtually impossible, error-prone, and causes alert fatigue for security analysts.

Proposed Solution

CyberVision AI bridges this gap with an intuitive, interactive web platform. It ingests CSV telemetry datasets, standardizes diverse schemas, runs heuristic and machine-learning anomaly detection, and presents dynamic visual dashboards and PDF audit reports.

Key Project Objectives

Automated Ingestion: Effortless drag-and-drop CSV upload with intelligent schema auto-mapping.
Behavioral Profiling: Unveil attack category patterns, protocol shares, and high-frequency threat origins.
Machine Learning Anomaly Detection: Apply Isolation Forest and Z-score outlier models without requiring manual rules.
Interactive Visualization: Reactive Chart.js visualizations that update dynamically upon filtering.
Audit & Export: Download clean filtered CSVs, raw analytical JSON, or compiled executive PDF briefs.

Benchmark Datasets & Data Sources

CIC-IDS2017 Dataset

Developed by the Canadian Institute for Cybersecurity (UNB). Features real-world network traffic benign and modern attack scenarios (DoS Hulk, DDoS, PortScan, Brute Force).

UNSW-NB15 Dataset

Created by the Australian Centre for Cyber Security. Contains synthetic modern normal and contemporary synthesized attack activities across 49 features.

Platform Scope & Limitations

  • Offline post-event dataset analysis only; does not provide real-time network interception or packet dropping.
  • Anomalies flagged are statistical and rule-based outliers; domain analyst verification remains necessary.
  • Initial release targets delimited tabular CSV files.

Future Scope & Enhancements

  • Real-time packet sniffing and PCAP direct streaming via Scapy or Zeek/Bro hooks.
  • Automated firewall rule generation and IP blocking via iptables / pfSense integrations.
  • Supervised deep learning models (Bi-LSTM, Autoencoders) for zero-day threat detection.
